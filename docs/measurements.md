# 日志字段

| 字段 | 含义 |
|---|---|
| `frame_ms` | 从 `VideoCapture.read()` 返回，到这一帧推理和后处理结束。 |
| `feedback_ms` | 从板端提交位移，到读到可确认该位移的帧。`-1` 表示该帧没有确认。 |
| `sent` / `hid_reports` | 是否写入移动报文 / 写入的移动报文数。 |
| `fired` | 按下和松开报文均已写入。命中看游戏画面。 |
| `feedback_timeout` | 画面没确认上一次位移，程序改用当前帧重新选靶。 |

`59.9 fps` 是程序处理帧的速率，未去重；`feedback_ms` 走完了一次 USB 输入、游戏渲染和 HDMI 采集链路，这三段没有单独计时。
